## 已知限制

- Registry 拉取按计划暂缓；`Runtime.PullImage` 返回不支持。
- 没有独立的插件元信息注册 API；注册由导入带 Manifest 标签的镜像隐式完成。
- 没有原地镜像升级 API；切换版本需卸载（默认保留镜像/数据）后重新安装。
- 安装/卸载/启动等异步操作先返回 `202`，状态冲突和 Docker 错误通过任务接口返回。
- 每个插件当前只允许一个实例；存储结构支持多实例。
- 配置只允许在停止状态修改；启动时重建容器，容器历史日志会从新容器开始。
- 健康记录/任务持久化有界；进程崩溃时正在执行的任务会被标记失败。
- 敏感变量加密不等同于操作系统密钥链；同用户权限的本地进程仍可读取密钥文件。
- 容器化部署时需显式把 Docker Socket 只挂载给 Lan Copy 主服务。
