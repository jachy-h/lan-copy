## 已知限制

- Linux rootless Podman 经 subuid 映射后可能无法写入宿主用户数据目录；建议 rootful socket 或 `podman machine`，本版不自动 chown。
- Podman 低于 4.1 可能不支持 `host-gateway`，loopback 访问宿主机 API 会失败。
- 已安装实例保存安装时的地址与 ExtraHosts；切换引擎后需卸载重装。
