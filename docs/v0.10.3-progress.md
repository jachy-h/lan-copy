## 已完成

| 模块 | 结果 |
| --- | --- |
| 标记存储 | `tablestore` 新增 `LoadMarks`、`SetMark`、`RemoveMarks`、`RelocateMarks`，保存到应用数据目录的 `table-marks.json`；原子写入、排序、损坏状态报错 |

| 移除独立入口 | 顶栏删除“智能表格”；`/tables`、`/tables.html` 302 到 `/`；静态导航、Vite 入口和资源同步移除 `tables.html` |
| 文案与文档 | README、README.en、DEVELOPING、PLUGIN-PROTOCOL 更新为“CSV 可选标记 + 内联视图”；插件 API 保持按路径访问任意 CSV |
| 测试 | 新增标记存储、标记接口、列表字段、重命名/删除联动与前端内联流程图测试 |
