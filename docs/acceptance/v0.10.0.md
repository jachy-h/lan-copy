## 兼容性与安全

- `state.json` 格式未变化；插件 API 令牌和事件令牌均由 SecretBox 派生，不落盘。
- 新增 `LAN_COPY_API_URL`、`LAN_COPY_API_TOKEN` 为保留环境变量，用户配置不能覆盖。
- 插件容器只增加固定 `host.docker.internal:host-gateway` 映射；任意其他 ExtraHosts、DNS、Host 网络或 Docker Socket 仍被拒绝。
- CSV 更新在现有文件锁内完成，与上传、删除、重命名互斥；失败不改变原文件。
- 页面和插件 API 使用同一版本校验；外部进程直接改文件时，版本冲突会阻止静默覆盖。
