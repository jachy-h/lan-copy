## 已完成

| 模块 | 结果 |
| --- | --- |

| 版本与并发 | 文件版本为内容 SHA-256；更新必须提交 `expectedVersion`；并发更新只有一个成功，另一个返回 409 |

## 与计划的差异

- 页面首期编辑采用“整行编辑 + 主键列选择”，没有实现逐单元格自动保存；保存仍使用 `lock_and_update`，语义一致。
- CSV 解析使用 Go 标准库 `encoding/csv`，字段内 CRLF 会按标准规范化为 LF，文件整体换行符仍保留。
- 表格列表通过既有目录遍历实现，单次最多扫描 10,000 个项目；超过时返回错误而不是部分列表。
