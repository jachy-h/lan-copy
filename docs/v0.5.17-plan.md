# Lan Copy v0.5.17 计划

制定日期：2026-11-13。在 v0.5.16 工作区上增量实现，不修改 `VERSION` 或发布配置。

## 背景与目标

“文本快传”目前只接受文字，内容永久保留，也无法转存到内网空间。实际使用中更多是临时截图、验证码、链接和一两段笔记：内容应尽快看到、到期自动消失，需要长期保留时再手动存入共享文件夹。

本版把“文本快传”改名为“碎片快传”，仍使用 `/transfer-text` 地址；一个“碎片”可以只包含文字、只包含图片，也可以同时包含文字和多张图片。支持粘贴、拖拽和点击添加图片；文字和图片默认 7 天到期，可在设置中调整；每条碎片都可以选择内网空间中的文件夹保存为普通共享文件。

## 范围与边界

- 页面名称、标题、导航和空状态改为“碎片快传”语义；保留 `/transfer-text` 路径和 `/transfer.html` → `/transfer-text` 的 308 重定向，避免已有链接失效。
- 文字限制保持 100,000 字 / 1 MiB；图片支持 PNG、JPEG、GIF、WebP、BMP，单张不超过 20 MiB，每条碎片最多 6 张；碎片总数量仍为 1000 条。
- 图片与文字共用碎片编号、列表排序、到期时间、删除和实时刷新事件；`kind` 区分文字、图片和图文混合。图片总占用上限 256 MiB，文字元数据仍受原 16 MiB 存储上限约束。
- 默认到期时间为 7 天，设置范围 1–365 天；修改只影响之后发布的碎片，已发布内容保留原到期时间。旧版本只有文字且没有到期字段的记录按创建时间补算默认 7 天，已经过期的历史记录在首次读取列表时清理。
- 到期清理采用读取时惰性清理：列表、创建和打开内容时移除已到期记录及图片文件，不新增常驻定时器或后台进程。
- “存入内网空间”只复制碎片，不移动、不删除碎片本身。文字保存为 `.txt`，图片保留原格式；图文碎片会把文字和每张图片分别保存，同名文件自动编号，绝不覆盖已有文件。
- 不新增账号、云存储、图片编辑、每碎片自定义到期时间、图片剪贴板复制或公开下载令牌。

## 数据与组件

- 继续复用 `internal/textstore` 作为碎片持久化组件，保留原元数据文件 `.lan-copy-texts.json` 和备份恢复语义；新增字段使用可选 JSON 字段，旧记录按文字读取并按创建时间补算到期。
- 图片保存在应用私有数据目录的 `.lan-copy-fragment-images/`，文件名为碎片 ID、序号和服务端检测出的扩展名；元数据记录 `images` 数组，每张图片包含 `name`、`mime`、`size`、`file`、`width`、`height`。服务端解析图片尺寸用于前端瀑布流布局。
- 到期设置保存在 `.lan-copy-fragments-settings.json`，采用临时文件替换；启动时由 `internal/app` 加载并注入 `textstore`，缺失或旧数据使用默认 7 天。
- 图片类型由服务端读取文件头检测，不信任上传声明的 MIME；不接受 SVG，避免脚本型内容进入共享图片通道。图片响应带 `default-src 'none'; sandbox` 的 CSP 和 `no-store`。
- 转存通过 `filestore.Store` 的新保存方法完成：目标目录使用既有 `Path` 校验，文件名使用既有组件规则，写入临时文件后原子替换，并用 `AvailableName` 处理重名。
- HTTP 层只负责 multipart/JSON 解析、动作校验和状态码映射；碎片业务与清理归 `textstore`，共享空间路径与写入归 `filestore`。

## API

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/texts` | 读取未到期碎片；响应同时提供 `texts` 和 `fragments` 字段 |
| `POST` | `/api/texts` | 发布纯文字碎片 |
| `POST` | `/api/texts/fragments` | 以 multipart 同时发布文字和最多 6 张图片 |
| `POST` | `/api/texts/images` | 以 multipart 字段 `image` 上传纯图片碎片（兼容入口） |
| `GET` | `/api/texts/{id}/image` | 读取第一张图片（兼容入口） |
| `GET` | `/api/texts/{id}/images/{index}` | 读取指定序号的图片，限制为已识别的图片类型 |
| `POST` | `/api/texts/{id}/save` | 将碎片复制到 `{path, name?}` 指定的共享目录；图文碎片返回多个文件 |
| `DELETE` | `/api/texts/{id}` | 删除碎片及其私有图片文件 |
| `GET/PUT` | `/api/settings/fragments` | 读取或保存默认到期天数 |

- 保持旧文字接口和字段兼容；新增响应字段不会要求客户端升级。
- `PUT /api/settings/fragments` 仅允许运行 Lan Copy 的本机调用，并要求 `X-Lan-Copy-Action: fragments`、同源 `Origin`/`Sec-Fetch-Site`，与上传资源设置一致。
- 转存使用与文件操作相同的路径错误语义；不存在、越界、符号链接或非目录目标均失败，不返回本机绝对路径。

## 页面与交互

- 顶栏、`<title>`、共享空间/打印页的初始骨架和浏览器测试统一使用“碎片快传”。
- 发布区使用轻量 Markdown 编辑器：支持加粗、斜体、行内代码和链接快捷插入，保留纯文本存储；文字与待发送图片在同一个编辑区预览，点击保存后作为一条碎片提交。
- 整张发布卡片接受图片拖拽，页面级 `paste` 监听支持直接粘贴截图，文件选择器支持一次选择多张图片；待发送图片可逐张移除，最多 6 张。
- 图片不单独立即发布，而是在点击保存时与文字一起提交；显示超大/非图片/数量上限提示和保存状态，避免重复提交。
- 列表用响应式瀑布流卡片展示：长文、宽图、多图和图文混合碎片占整行，短文、窄图和纯文字短内容占半行；图片尺寸由服务端元数据或浏览器加载结果决定。
- 文字使用安全转义后的轻量 Markdown 渲染；长文默认折叠，点击“展开”扩大高度，只有展开后仍超出最大高度时才显示滚动条。
- 卡片保留复制、删除、到期和“存入内网空间”操作；图片可点击在新标签查看原图，图文碎片同时展示文字和图片缩略图。
- 每条碎片提供“存入内网空间”动作，弹窗采用左右两栏：左侧复用与内网空间相同的目录树组件，右侧显示当前文件夹、面包屑、文件名和保存动作；支持上一级、修改文件名、记住上次保存的文件夹，并对读取中、读取失败和保存失败给出明确状态。
- 每条碎片以独立卡片展示，信息和操作按钮归属同一条内容；列表使用压缩的响应式网格，减少垂直占用，图片缩略图限制高度。
- 到期时间使用卡片底部的细进度条表示剩余比例，并在信息行以小字标注“N 天后到期 / HH:mm 后到期”，每分钟更新；无到期字段的兼容记录显示“长期有效”。已到期显示“已到期”，页面会触发一次刷新，实际清理发生在下一次读取列表时。
- 右键菜单新增“存入内网空间”；页面空白菜单新增“添加图片”。原有刷新、聚焦输入框和复制页面地址保留。

## 追加交互调整（2026-11-13）

在现有图文碎片、瀑布流和转存能力上追加以下界面修正，不改变存储格式、既有 API 或到期语义。

1. **待发送图片可点击查看。** 发布区附件缩略图增加独立的查看按钮，点击后用现有 `AppDialog` 打开大图预览；移除按钮与查看按钮事件分离，关闭或按 Esc 后焦点返回原缩略图。预览使用本地 `blob:` 或降级后的 `data:` 地址，不新增服务端接口。
2. **图文混合碎片始终占整行。** `isWide` 在现有“长文、宽图、多图”规则前增加判断：同一碎片同时包含文字和至少一张图片时直接占整行。纯短文字、纯窄图仍占半行；长文、宽图和多图规则保持。
3. **压缩发布区底部操作行。** 将 `+ 图片`、字数统计和保存按钮放在同一行，`+ 图片` 靠左，字数统计紧挨在保存按钮左侧；降低按钮高度和内边距，窄屏允许换行但不溢出。移除“文字和图片会作为同一条碎片发送，”整句，单张 20 MiB 限制仅保留在按钮的 `title`/`aria-label` 和错误提示中。
4. **按平台显示提交快捷键。** 保存按钮旁提示 macOS 的 `⌘ + Enter` 或其他平台的 `Ctrl + Enter`；继续支持 `Ctrl/Meta + Enter` 提交。快捷键文案根据 `navigator.platform`/UA 判断，不硬编码成单一平台。
5. **同步初始骨架与测试。** 更新 `frontend/transfer.html` 的发布区骨架，避免 Vue 挂载前后布局跳动；补充附件预览、混合碎片整行、快捷提示和底部操作行测试，并更新 Chromium 浏览器回归中依赖保存按钮文本的选择器。

**退出条件：** 待发送图片可点击预览并正常关闭；图文混合碎片占整行；底部操作行在 1280/768/390px 下不溢出；macOS 显示 `⌘ + Enter`，其他平台显示 `Ctrl + Enter`；字数位于保存按钮左侧；指定提示文案已移除；前端检查、Go 测试和 Chromium 回归通过。

### 图片查看统一弹窗（2026-11-13 追加）

- 碎片瀑布流中的已发布图片不再使用 `<a target="_blank">` 打开新标签，改为与待发送图片共用同一个图片预览弹窗。
- 预览弹窗接收统一的 `{ url, alt }` 数据：待发送图片使用 `blob:`/`data:` 地址，已发布图片使用 `/api/texts/{id}/images/{index}` 地址。
- 点击待发送缩略图或已发布图片都打开同一 `AppDialog`；关闭按钮或 Esc 关闭后，焦点返回对应的缩略图或图片按钮。
- 不新增图片下载、左右切换或缩放功能；不改变图片编辑、删除、转存和到期行为。
- 测试覆盖待发送图片和已发布图片的同一弹窗路径、关闭后焦点返回，以及浏览器中点击已发布图片不再创建新标签。

**退出条件：** 待发送图片与已发布图片均只通过同一弹窗查看；点击已发布图片不发生页面跳转或新标签打开；原图片地址、删除/转存/到期逻辑不变；前端检查、Go 测试和 Chromium 回归通过。

### 弹窗外部点击关闭（2026-11-13 追加）

- 在共享 `AppDialog` 中统一处理遮罩点击：仅当点击目标是 `dialog` 自身时关闭，点击弹窗内容不触发。
- 增加 `closeOnBackdrop` 属性，默认开启；保存弹窗在 `pending` 时关闭该能力，避免提交中误关闭，其余确认、移动、图片预览弹窗默认支持点击外部关闭。
- 保留现有 Esc/取消行为；点击外部关闭同样通过 `update:open` 事件通知调用方，并沿用各弹窗的焦点返回逻辑。
- 不改变弹窗内部按钮、表单提交和保存请求；点击外部只关闭界面，不取消已经开始的请求（提交中的保存弹窗不允许关闭）。
- 测试覆盖：点击内容不关闭、点击遮罩关闭、保存中禁用外部关闭，以及图片预览遮罩关闭的浏览器回归。

**退出条件：** `AppDialog` 弹窗点击外部可关闭；点击弹窗内容不关闭；保存请求进行中不会因遮罩点击关闭；现有 Esc/按钮关闭和焦点返回不回归；前端检查、Go 测试和 Chromium 回归通过。

### 移除碎片编辑格式工具栏（2026-11-13 追加）

发布区回到纯文本输入，只移除“编辑时”的格式能力，不改变已发布内容的存储与展示。

- 删除发布区的加粗、斜体、行内代码、链接四个工具栏按钮、工具栏容器和“支持加粗、斜体、代码和链接”提示文案，同时移除 `.fragment-editor-toolbar`、`.fragment-editor-link`、`.fragment-editor-tip` 样式。
- 删除 `Ctrl/⌘ + B/I/K` 格式快捷键，以及只为工具栏服务的 `applyFormat`、`wrapSelection`；输入框不再 `preventDefault` 这些组合键。`Ctrl/⌘ + Enter` 保存保持不变。
- 已发布碎片的展示渲染保持不变：`renderText` 继续在转义后渲染历史内容中的 `**加粗**`、`*斜体*`、行内代码、显式链接和裸链接，避免旧碎片显示为原始符号。本轮不改变存储格式，也不清洗历史数据。
- 同步 `frontend/transfer.html` 初始骨架，去掉工具栏占位，避免 Vue 挂载前后布局跳动。
- 测试：删除或改写依赖工具栏按钮和格式快捷键的用例，新增“发布区不再包含格式按钮与提示”“`Ctrl+B` 不插入 Markdown 且不阻止默认行为”用例；保留 Markdown 渲染用例。
- 不做：不引入富文本编辑器，不移除已发布内容的链接/强调渲染，不改动图片、到期、转存和保存快捷键。

**退出条件：** 发布区没有格式按钮、提示文案和空工具栏；`Ctrl/⌘ + B/I/K` 不再改写输入内容也不再被拦截；历史碎片的加粗、斜体、代码和链接渲染与之前一致；前端 `npm run check`、单元测试通过，Chromium 中发布区布局无跳动。

### 二：HTTP 接口与共享空间转存

新增图片上传/读取、碎片转存和到期设置接口；完善大小、类型、动作头和路径校验；补充 HTTP 生命周期与错误测试。

**退出条件：** 图片上传、读取、删除和转存通过；目标目录越界或不存在被拒绝；同名文件自动编号；设置仅本机可写。

### 三：碎片快传页面

重命名页面与导航，加入粘贴/拖拽/点击选图、图片列表、到期标签、右键动作和文件夹选择弹窗；保持原有文字发布、复制、刷新、SSE 和草稿行为。

**退出条件：** 前端类型检查与单元测试通过；粘贴、图片渲染、保存弹窗和设置保存均有覆盖；窄屏布局不溢出。

### 四：构建与验收

构建前端并同步内嵌资源，运行 Go 测试与跨平台构建检查；在真实浏览器中验证粘贴、拖拽、点击上传、到期显示和转存到子目录。

**退出条件：** `go test ./...`、前端 `npm run check`、`make build` 通过；`/transfer-text` 和旧重定向仍可用；共享文件、打印队列和设置其他页签无回归。

## 验证要求

- Go：`internal/textstore`、`internal/filestore`、`internal/httpserver`、`internal/app` 的受影响测试；图片类型检测、到期清理、重名保存、路径越界和设置持久化。
- 前端：`npm run typecheck`、`npm test`、`npm run build`；片段粘贴上传、图片渲染、保存弹窗、设置表单和原有文字/导航测试。
- 真实浏览器：Chromium/Firefox/WebKit 中至少验证图片粘贴、拖拽和点击上传；转存到根目录和子目录；同名保存生成编号副本；到期时间更新后新碎片使用新值。
- 明确记录未验证项。到期依赖列表/创建时清理，不把“时间一到界面立即消失”作为本版承诺。

## 不做事项

- 不改变碎片总量上限、文字上限或现有共享文件上传协议。
- 不将图片写入 `.lan-copy-texts.json` 或共享目录；共享目录只接收用户明确转存的文件。
- 不提供图片压缩、裁剪、OCR、相册管理或自动清理策略配置。
- 不新增后台定时清理进程，不延长已发布碎片的到期时间。
- 不修改 `/transfer-text` 地址、旧重定向、数据文件名称或恢复语义。
