## 已完成

- Manifest 新增 `uploadHook`（`path`、`timeoutSeconds`）解析、默认值、路径与超时校验。
- 新增 `internal/plugin/upload_hook.go`：
  - 只选择运行中且健康的插件实例；
  - 复用 `LAN_COPY_EVENT_TOKEN` HMAC-SHA256 签名；
  - 并发调用、单插件超时、不重试；
  - 解析 `dialogs`，校验标题、相对路径、协议头和外部 URL；
  - 单插件 5 个、总计 10 个弹窗上限；
  - 复用插件 Client 的调用指标与响应大小限制。
- `/api/upload-tree` 提交成功后返回可选 `pluginDialogs`；Hook 失败、超时或无效响应不影响 201。
- 抽出 `uploadEventData`，生命周期事件和上传 Hook 共用同一份上传元数据。
- 主页面 CSP 显式加入 `frame-src 'self'`。
- 前端新增 `processing` 上传阶段和“等待插件处理”提示。
- 新增 `PluginDialog.vue`：
  - 原生 `<dialog>` + 同源 iframe；
  - 仅接受来自当前 iframe 且同源的 `postMessage`；
  - 支持关闭与完成消息，完成后刷新文件列表。
- `FileExplorer.vue` 解析上传响应、维护弹窗队列，并在完成时刷新目录与目录树。
- `api/plugins.ts` 新增 `PluginDialog` 解析，前端再次过滤非 `/plugin-app/` 地址。
- 协议文档、README、Agent Prompt 和示例说明已更新。
- 嵌入资源已重新构建并同步到 `web/`。
- `VERSION` 更新为 `0.13.0-build2`，与本版计划一致。
- `AGENTS.md` 增加版本同步规则：后续代码改动必须同步更新 `VERSION`，涉及插件协议、上传 Hook、HTTP API 或对外通信格式时同时更新插件版本、Manifest/Dockerfile 标签和最低兼容版本说明。
