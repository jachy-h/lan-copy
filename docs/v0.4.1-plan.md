# Lan Copy v0.4.1 计划

## 目标

让用户启动自动更新后能立即看见更新正在进行，避免误以为“下载并更新”按钮没有响应。

## 改动

- 自动更新开始后，将“正在下载更新包并校验，请稍候…”显示在“下载并更新”按钮正下方。
- 使用比普通说明文字更醒目的状态颜色和适当字号；维持现有页面配色，不使用错误状态的红色。
- 状态提示在下载与校验期间持续显示；自动更新结束、失败或设置页关闭时，按现有流程更新或清理状态。
- 为状态提示保留 `role="status"` / `aria-live="polite"`，使辅助技术能够播报更新进度状态。
- 手动更新区域的状态与进度行为不受影响。

## 主要改动位置

- `web/settings.js`：自动更新状态切换时，将提示写入下载按钮下方的专属状态元素。
- `web/style.css`：增加自动更新状态提示的醒目样式及窄屏间距。

## 验收

- 点击“下载并更新”后，提示紧跟在按钮下方出现，颜色和字号足以与一般说明文字区分。
- 下载及校验期间提示保持可见；请求失败时错误状态清楚显示，成功时沿用现有重启与刷新行为。
- 键盘和屏幕阅读器用户可感知状态变化；手动更新流程不受影响。
