## 已完成

- 新增 `frontend/src/preview/delimitedText.ts`：RFC 4180 线性扫描解析，支持引号、`""` 转义、字段内逗号/换行、CRLF/LF、BOM、空行跳过、行宽补齐、行列上限与未闭合引号标记。
- 预览引擎 `.csv`/`.tsv` 表格视图：
  - 按扩展名选择逗号或制表符，首条记录作为表头；
  - Range 最多读取 1 MiB，超过 250 行 × 50 列或读取截断时在状态栏提示；
  - 截断时丢弃最后一个不完整记录；
  - 复用 Excel 预览的表格 DOM 与样式，带行号列、表头吸顶、首列吸左；
  - 工具栏“原始文本 / 表格”切换，编码选择器对两种视图都生效；
  - 识别 UTF-16 BOM，空文件显示空状态，未闭合引号降级解析并提示。
- 抽出 `renderTable`，xlsx/xls 与 CSV 共用同一套表格结构。
- 样式新增 `.preview-csv-tools` 基础与工具栏紧凑规则。
- README 与 README en 补充“CSV/TSV 直接表格预览、可切换原始文本”。
- 浏览器测试新增 CSV 表格预览、原始文本切换与关闭返回列表检查。
- 嵌入资源已重新构建并同步到 `web/`。
