# Lan Copy v0.5.17 进度

更新日期：2026-11-13。版本号保持 `0.5.16`，不修改 `VERSION` 或发布配置。

## 当前状态

本轮“移除碎片编辑格式工具栏”已实现并验证。版本号保持 `0.5.16`，不修改 `VERSION` 或发布配置。

## 已验证

- 页面与导航已改名为“碎片快传”，`/transfer-text`、旧 `/transfer.html` 重定向保持兼容。
- 碎片支持纯文字、纯图片和图文混合；文字最多 100,000 字，图片最多 6 张、单张 20 MiB，支持 PNG/JPEG/GIF/WebP/BMP。
- 默认 7 天到期，设置页可调整为 1–365 天；旧记录按创建时间补算 7 天，已过期历史记录在列表读取时清理。
- 发布区使用项目内自研的轻量 Markdown 工具栏与渲染器，没有引入第三方编辑器或 Markdown 解析库。
- 已移除发布区的加粗、斜体、行内代码、链接按钮、工具栏容器与提示文案，以及 `Ctrl/⌘ + B/I/K` 格式快捷键和 `applyFormat`/`wrapSelection`；`Ctrl/⌘ + Enter` 保存保持。
- 已发布碎片的 `renderText` 渲染保持不变，历史碎片里的强调、行内代码、显式链接和裸链接仍按原样展示。
- 碎片使用半行/整行瀑布流卡片；长文可展开，展开后仍超过上限才显示滚动条。
- 存入内网空间使用左右两栏弹窗，左侧复用 `FileTree.vue`，支持文件名、面包屑、上一级和目录记忆。
- 图文碎片转存会分别保存文字和每张图片，同名文件自动编号。
- 待发送图片支持粘贴、拖拽、点击选择、预览和移除；已修复 `files`/`items` 重复导致的同一图片添加两次问题。
- 已修复 `blob:` 预览被 CSP 拦截的问题，`img-src` 已包含 `blob:`，并保留 `data:` 降级。
- Chromium 真实浏览器已验证图文混合发送、粘贴/拖拽/点击、重复粘贴修复、刷新后单图、长文展开和转存。
- 待发送图片缩略图可点击打开大图预览，关闭后焦点返回缩略图。
- 同时包含文字和图片的碎片始终占整行；纯短文字、纯窄图仍占半行。
- 发布区底部已压缩为同一行：左侧 `+ 图片`，右侧字数统计紧邻保存按钮。
- 保存按钮根据平台显示 `⌘ + Enter` 或 `Ctrl + Enter`，提交快捷键保持 `Ctrl/Meta + Enter`。
- 已移除“文字和图片会作为同一条碎片发送，”提示，单张 20 MiB 限制保留在添加图片按钮的标题和无障碍标签中。
- `frontend/transfer.html` 初始骨架已同步为不含工具栏的输入框和底部操作行，Vue 挂载前后布局不跳动。
- 待发送图片和已发布图片统一使用同一个图片预览弹窗；已发布图片不再打开新标签。
- 预览弹窗统一接收 `{ url, alt }`，关闭或按 Esc 后焦点返回对应图片按钮。
- 共享 `AppDialog` 支持点击弹窗外部的遮罩关闭；点击弹窗内容不关闭。
- 保存弹窗在请求提交中禁用遮罩关闭，避免请求进行中误关闭；关闭或 Esc 的原有行为保持。
