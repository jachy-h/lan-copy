## 与计划的差异

- 计划的 `text.updated` 改为 `text.saved`。当前没有“覆盖已有碎片内容”的接口，实际生命周期是“碎片转存为共享文件”，事件数据为 `id` 与 `files`。
- 签名示例只保留 Go 标准库版本，避免在页面维护第二套容易过期的 Node.js 示例；事件目录和信封示例仍完整展示。
- 事件密钥随实例重装轮换；旧实例在升级后需要重启一次才能获得容器内的 `LAN_COPY_EVENT_TOKEN`。密钥不落盘，插件状态格式与旧版本兼容。
