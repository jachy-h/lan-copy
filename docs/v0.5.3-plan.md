# Lan Copy v0.5.3 计划

制定日期：2026-10-26。基于当前 v0.5.2 工作区。

## 背景与目标

共享空间中不可预览文件的名称链接直接指向文件下载地址，点击会立即下载。v0.5.3 将该行为改为明确提示“该文件格式暂不支持预览”，不发起文件下载。

## 范围与方案

- 文件名点击、文件行双击及右键菜单操作统一通过文件入口处理；不可预览文件显示提示，支持预览的文件和目录保持现有行为。
- 不修改下载 API、文件格式识别或存储行为。
- 保持单二进制和嵌入式前端，完成前端构建并同步嵌入资源。

## 验收

确认不可预览文件的列表链接不再指向下载接口，且所有列表操作入口均显示提示；支持预览文件和目录行为不变。前端检查及真实浏览器检查记录在 [v0.5.3-progress.md](v0.5.3-progress.md)。
