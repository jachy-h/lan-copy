# Lan Copy v0.10.2 插件服务入口收进设置计划

更新日期：2026-11-19。状态：**已批准并完成实现，自动化验证通过，待人工验收**。

## 背景与目标

插件服务是低频的本机管理功能，目前与“内网空间、智能表格、碎片快传”并列占据顶栏主流程。主流程应优先服务日常文件与表格操作，插件管理入口收进设置更符合使用频率。

本版目标：

1. 顶栏移除“插件服务”，主流程只保留内网空间、智能表格、碎片快传与打印队列。
2. 设置中加入“插件”入口，说明插件服务的用途，并提供“在新标签页打开插件服务”的主操作。
3. 现有的 `/plugins` 独立页面与 `/plugins/installed`、`/plugins/images`、`/plugins/integration` 子路由保持可直接访问、刷新、前进后退和收藏。
4. 新标签页使用原生链接 `<a target="_blank" rel="noopener noreferrer">`，保留中键、右键和键盘的新标签打开方式。

## 已确认的边界

- 只调整入口位置，不改变插件页面结构、API、权限、动作头、同源检查和局域网可管理语义。
- 不把插件管理界面嵌入设置对话框，设置只承载入口与说明。
- 不改变 `/plugins` 直达行为；未从设置进入时仍可正常打开。
- 不改 Go 服务端、插件运行时、状态文件和静态资源同步机制。
- 桌面端与移动端设置菜单保持键盘可访问，不出现横向溢出。

## 非目标

- 不重新设计插件服务页面，不调整插件列表、镜像、对接页的交互。
- 不根据当前页面隐藏入口；设置在所有页面中保持一致。
- 不为插件服务增加未读、运行状态等实时角标。
- 不删除 `/plugins` 路由，也不改变打印队列和分享入口。

## 一、顶栏与路由

- `frontend/src/components/AppHeader.vue`：移除 `/<plugins>` 导航链接；主导航类型收敛为内网空间、智能表格、碎片快传和打印队列。
- `frontend/src/App.vue`：保留 `page === 'plugins'` 的路由识别、页面标题和 `PluginManager` 渲染，直接访问 `/plugins` 仍可用；移除已无调用方的顶栏 `plugins` 跳转分支。
- `frontend/plugins.html`：首屏静态导航移除“插件服务”，页面标题与首屏插件占位内容保留。
- `frontend/index.html`、`transfer.html`、`print.html`、`tables.html`：首屏静态导航同步移除“插件服务”，避免水合前闪现旧入口。

## 二、设置入口

`frontend/src/components/SettingsDialog.vue`：

- 侧栏新增第 6 个设置页“插件”，描述为“安装与运行插件”，`data-settings-tab="plugins"`，纳入现有方向键、Home、End 循环。
- 页面内容：
  - 标题“插件服务”。
  - 说明：插件在受限容器中运行，局域网内可管理，仅安装可信镜像。
  - 主操作链接：`href="/plugins"`、`target="_blank"`、`rel="noopener noreferrer"`，文案“在新标签页打开插件服务 ↗”。
  - 次要说明：插件页面包含安装、镜像、对接事件和智能表格 API 文档。
- 复用现有 `.settings-content`、`.primary` 与链接样式；移动端菜单由 5 项变为 6 项，检查 360–390px 宽度下的布局。
