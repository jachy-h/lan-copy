## 实现与兼容边界

- `/` 和 `/transfer-text` 提供各自初始加载骨架，随后挂载相同应用；旧 `/transfer.html` 以 HTTP 308 重定向到 `/transfer-text` 并保留查询参数，Go 和 Vite 开发服务行为一致；预览页继续独立。删除原 `files.ts`、`transfer.ts`、`shell.ts`、`settings.ts` 多次挂载入口，A/B 测试探针同步改用 `app.ts`。
- HTTP API、Go 服务组装、嵌入路径及普通 `go run .` / `go build .` 入口保持兼容；Go 页面测试验证旧文本地址的 GET/HEAD 重定向、查询参数保留及公共 `#app` 挂载点，保留加载骨架、导航和历史地址检查。
- 运行时顶栏和页脚复用 Vue 组件；两个 HTML 中的静态导航/加载骨架是 Vue 加载前的回退结构。
