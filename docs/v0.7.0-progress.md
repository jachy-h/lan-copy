# Lan Copy v0.7.0 进度

更新日期：2026-11-17。状态：**架构已调整，等待确认；未修改源代码**。

## 当前状态

已按“独立 OCR 镜像 + Lan Copy 本地服务管理”的方向重写计划，见 [v0.7.0-plan.md](v0.7.0-plan.md)。

当前代码没有 Docker、容器或插件服务管理实现，因此本版需要新增：

- `internal/containers`：Docker CLI 适配。
- `internal/servicehost`：受控的服务清单、生命周期、健康检查和状态恢复。
- `ocr-worker`：独立 OCR 容器镜像。
- 发票领域、OCR Client、发票存储和前端页面。

本阶段只修改计划与进度文档，没有修改 Go、Python、Vue、构建配置或数据格式。

## 已验证

- 当前项目为 Lan Copy：Go 单二进制 + 内嵌 Vue SPA。
- 当前没有 Docker/容器/服务管理能力，也没有数据库/ORM/通用任务队列。
- 文件共享由 `internal/filestore` 管理，文件浏览器支持多选和右键菜单。
- 现有文件列表、预览、下载和打印边界可复用为发票识别入口。
- 通过 `uv` 实测 RapidOCR 3.10.0 + ONNX Runtime 1.32.0 可加载 PP-OCRv5 Mobile 并完成识别。
- PP-OCRv5 Mobile 检测 + 识别模型合计 21,450,882 字节（20.46 MiB / 21.45 MB），超过 20MB 目标。
- 未启用方向分类模型时不会下载或加载该模型。
- 当前最新 Python 依赖组合虚拟环境约 441MB；镜像最终体积需构建后统计。
