## 本版行为与边界

- 入口为现有打印队列页面选择本地单个文件，或共享空间支持文件的「⋯ → 打印」；原文件不加入共享空间。支持 PDF、JPG/JPEG、PNG；原文件 50 MiB、PDF 50 页限制。加密 PDF 提示先另存为无密码文件。
- Windows 返回物理纸张、可打印区域和版面标识；浏览器把内容居中缩放至该区域，预览可以翻页和放大/缩小。纸张与方向跟随主机默认设置，固定 1 份、单面。
- 打印为 200 DPI 栅格页面，不保留 PDF 矢量输出。单页 PNG 最大 12 MiB/1600 万像素，总页面最大 128 MiB；浏览器先准备所有压缩页，再以一个 multipart 请求发送，较复杂/多页文件可能触发总量限制。
- 后端只接收有序已渲染 PNG 页面及文档元数据，逐页校验并暂存到应用私有 `print-spool/`。所有页面完整后才打印；失败不自动重试。启动只清理能确认的自有遗留目录，不重放任务。
- 任务历史仍为本次启动后最近 50 条；新增名称、页数、接收状态与清理警告。“已提交”只代表交给 Windows 队列，不能确认物理出纸。
- 保持单进程、单二进制、嵌入前端，无额外打印软件或 PDF 原生 DLL。没有改 VERSION、安装依赖版本或执行发布。
