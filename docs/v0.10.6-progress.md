## 已完成

- 文件类型聚合：图片、视频、音频、文档、压缩包、代码/文本、其他，按字节降序返回；`/api/storage` 与 `/api/resource-usage` 均包含 `types`。
- `internal/processstats`：Lan Copy 进程 CPU 差分采样与运行时内存；Unix 使用 `Getrusage`，Windows 使用 `GetProcessTimes`，其他平台降级为不可用。
- `plugin.Manager.Usage`：并发采样运行中插件，汇总 CPU/内存/PID，单项失败不影响其他数据。
- `GET /api/system-usage`：返回 Lan Copy 与插件实时占用，插件聚合 3 秒超时。
- 资源页拆为上下两部分：“资源详情”（占用卡片、文件类型堆叠图、Lan Copy/插件运行占用）和“资源配置”（原上传限制表单）。
- 实时占用每 2 秒自动刷新；关闭弹窗、切换页签或组件卸载时停止；页面隐藏时跳过本轮。
- 前端测试、开发文档与 API 文档更新。
