## 实现结果

### 预览生命周期与类型

- `frontend/src/preview/engine.ts` 替代旧 JS 与仅声明入口的 `.d.ts`，`pdf.ts` 提供实际使用的最小第三方类型边界，PDF.js 仍从本地 vendor 按需加载。
- 在 import、PDF 文档加载、取页、渲染和文本 body 完成之后检查终止状态，旧结果不会写入后续预览；重复调用 destroy 不会清空新内容。
- 关闭时取消活动 PDF 渲染、销毁加载任务、终止表格 Worker、拒绝待处理表格请求、清理 resize 定时器及媒体资源。FileExplorer 的静态 dialog 监听器使用所属组件的 AbortController 清理。
- 清理未使用的 `App.vue` / `pages/mount.ts` 迁移脚手架。

### 页面、资源与缓存

- `frontend/*.html` 是三个页面的唯一来源，`frontend/src/style.css` 是公共样式源。Vite 生成的 HTML 写入 `web/`，完整静态资源树写入 `web/_frontend/`；独立维护的 logo/vendor 不被覆盖。
- 同步脚本验证完整 manifest 的静态/动态依赖、CSS、资源文件，以及生产 HTML 的本地引用；不依赖每个 HTML 都在 manifest 中保留独立 entry（Vite 可合并相同入口）。
- 临时副本在 `tmp/` 中，替换失败恢复原资源；若恢复本身失败，保留恢复副本并报告路径，不删除唯一备份。
- 带内容 hash 的现存资源长期缓存；HTML、固定路径资源和缺失旧 chunk 使用 `no-cache`。旧懒加载失败时自动刷新一次；连续失败显示手动刷新，防止循环。

### 依赖与构建

- `frontend/vendor-manifest.json` 记录 PDF.js 6.4.299、docx-preview 0.4.1、JSZip 3.10.2、SheetJS CE 0.20.3 的来源、许可、上游 SHA-512 和选中文件 SHA-256。
- `scripts/vendor_assets.py` 提供离线校验、上游包验证及显式更新；校验覆盖文件修改、遗漏与额外文件。修正 DOCX README 的上游摘要笔误；实际库文件与上游逐字节一致，未升级预览库。
- 新增 Playwright 1.58.2 作为开发依赖，浏览器及测试代码不进入 Go 内嵌产物。Make、Windows 发布脚本与 CI 接入 vendor 检查；CI 增加真实内嵌服务浏览器任务并作为签名构建依赖。
- `VERSION`、`frontend/package.json` 和 lockfile 同步为 0.5.1。保持根目录 Go 入口、HTTP API、存储格式与恢复逻辑。

### 真实浏览器集成

`cd frontend && npm run test:browser` 在 Playwright Chromium `145.0.7632.6`、Firefox `146.0.1`、WebKit `26.0` 上通过。服务与样本在临时目录创建，测试结束清理，不操作用户共享数据。

- 弹窗和独立页加载实际 PDF.js、DOCX 与 XLSX 库；PDF 样本含 JPEG 图片，检查实际渲染像素、分页与正常状态；XLSX 使用真实 Worker。
- 文本预览与 206 Range 返回、DOCX/XLSX 文本内容、重复打开与关闭、延迟 PDF 模块加载后关闭、断网失败提示、文本发布通过。
- 页面错误与页面 CSP 违规收集未发现异常，未放宽生产页面安全策略。
- 缓存头、缺失旧 chunk、自动重载一次与连续失败后的手动重试通过。
- 另在隔离副本构建 A、B 两套真实内嵌二进制，以测试插件生成不同 hash 和一个实际懒加载入口：打开 A，换成 B，旧标签页触发 A 的懒加载，Vite 发出 preloadError 后自动重载 B；再次刷新保持 B。测试插件不会写入生产源码或产物。
- Node 构建测试使用真实 Vue SFC scoped style、懒加载和嵌套 SVG，确认完整同步且无资源遗漏。
