## 已完成

- Manifest 新增可选 `ui.path`，缺省归一为 `/`；校验拒绝相对路径、`..` 和查询串，未知字段仍拒绝。
- `plugin.Manager.ProxyTarget`：每次请求解析运行中且健康的实例，区分未安装、未运行、不健康和无 `ui`。
- `/plugin-app/{id}/...` 反向代理：
  - 无尾斜杠时 308 跳转并保留查询串；
  - 转发方法、查询串、请求体和原始路径，拼接 `ui.path`；
  - 附带 `X-Forwarded-Host`、`X-Forwarded-Proto`、`X-Forwarded-Prefix`，`X-Forwarded-For` 由 ReverseProxy 追加；
  - 改写根绝对路径及指向内部/公开主机的 `Location`、`Content-Location`；
  - 移除 Lan Copy 的 CSP 与 X-Frame-Options，保留上游安全头；
  - `FlushInterval = -1`，复用长连接 Transport，响应头超时 60 秒；
  - 上游失败 502，未声明界面/未安装 404，未运行/不健康 503 并带 `Retry-After`。
- 插件页在 Manifest 声明 `ui` 时显示“打开界面”，运行且健康后可点击；详情页显示完整地址和“复制地址”。
- “对接”页新增“插件 Web 界面”卡片，写明 Manifest `ui` 声明、`/plugin-app/{id}/` 入口、`X-Forwarded-Prefix` 约定、运行/健康限制和同源安全提示；“复制对接说明”生成的 Agent Prompt 同步增加该章节。
- 协议文档新增“插件 Web 界面”章节，补充安全边界、排错表和 API 能力表。
- 示例插件增加 `GET /` 页面，读取 `X-Forwarded-Prefix` 并通过同前缀调用 `/version`；Manifest 与 OCI 标签同步增加 `ui`。
- README、README.en.md、DEVELOPING.md 与插件示例 README 同步说明。
