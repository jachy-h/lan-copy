## 已完成

- [x] `tablestore` 新增 `layout.go`：
  - 侧车路径 `<完整表格文件名>.hidden.metadata.json`；
  - 读取容忍缺失、损坏、未知版本和超大文件；

  - `SaveLayout` 通过通用原子写入保存；
  - `RelocateLayout` / `RemoveLayout` 处理表格重命名、移动和删除。
- [x] `filestore` 新增：
  - `WriteFile` 原子创建/替换；
  - `IsHiddenMetadata` 与保留后缀识别；
  - 目录列表、搜索和 `ListFiles` 过滤内部元数据；
  - 上传目录、文件保存、目录变更拒绝保留后缀。
- [x] 文件下载、预览、缩略图、本机打开和删除拒绝元数据文件。
- [x] `POST /api/tables/query` 浏览器响应附带 `layout`，插件 API 响应不变。
- [x] 新增 `POST /api/tables/layout`，要求 `X-Lan-Copy-Action: tables`。
- [x] 表格重命名/移动同步侧车，删除表格清理侧车；目录移动无需改写 JSON。
- [x] 前端 `SmartTable.vue` 增加列设置面板：
  - 上移/下移、显示复选框、全部显示；
  - 任意列都可隐藏（包括记录标识列），新增行时临时显示记录标识列；
  - 隐藏当前排序列时清除排序条件；

- [x] `api/tables.ts` 增加 `TableLayout`、查询响应 `layout` 和 `saveTableLayout`。
- [x] 样式与窄屏布局。
- [x] README、README.en、DEVELOPING、PLUGIN-PROTOCOL 更新。
