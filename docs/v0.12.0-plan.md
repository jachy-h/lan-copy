# Lan Copy v0.12.0 CSV 表格预览计划

更新日期：2026-11-23。状态：**已批准并完成实现，自动化验证通过，待人工验收**。

## 背景与目标

共享目录中的 `.csv` / `.tsv` 文件目前被 `previewContentType` 归类为 `text/plain`，在内网空间里直接打开时按原始文本显示逗号分隔内容。要看清一张表需要先把它标记为“智能表格”，而标记会引入插件 API、主键、可编辑等额外语义，对只是想“看一眼”的文件来说太重。

本版把 CSV/TSV 的**只读预览**改成表格展示：

1. 在内网空间或独立预览页打开 `.csv` / `.tsv`，默认渲染为和 Excel 预览外观一致的表格：首行为表头，带行号列，表头吸顶、首列吸左，支持横向与纵向滚动。
2. 顶部工具栏保留“查看原始文本 / 查看表格”切换，编码选择器对表格同样生效。
3. CSV 解析只用于展示，不写回文件，不引入主键、编辑或插件 API 语义。
4. 不改变“智能表格”的标记流程：需要编辑、查询或插件读写的文件仍先标记为智能表格。

## 已确认的决策

- 用户选择了“CSV 预览直接渲染成表格”，本版只改预览，不改智能表格页面外观。
- 复用现有 `.preview-sheet-table` 样式与 `renderSheet` 的视觉结构，保证 CSV 与 xlsx/xls 预览一致。
- 分隔符按扩展名固定：`.csv` 用逗号，`.tsv` 用制表符；不做自动嗅探，避免歧义。
- 后端 `previewContentType` 继续返回 `text/plain; charset=utf-8`，不在服务端解析 CSV；表格化只发生在前端预览引擎内，HTTP 语义与安全策略不变。

## 非目标

- 不自动把普通 CSV 变成“智能表格”，不改 `tablestore` 标记、查询与更新逻辑。
- 不支持 `.xls` / `.xlsx` 之外的二进制表格格式变化；CSV 解析不使用 SheetJS。
- 不做 CSV 编辑、导出、列筛选、排序或分页；预览页仍然是只读。
- 不做超大文件的全量渲染、流式解析或后台 Worker；超出上限时明确提示并引导下载。

## 行为与限制

| 项目 | 规则 |
| --- | --- |
| 触发条件 | 路径扩展名为 `.csv` 或 `.tsv`，且响应 `Content-Type` 为 `text/plain`（或为空） |
| 读取量 | `Range: bytes=0-1048575`，最多 1 MiB；头部 `Content-Length` 更大时视为截断 |
| 行 / 列上限 | 与 Excel 预览一致：最多 250 行数据、50 列 |
| 表头 | 第一条记录作为表头；空文件提示“空表格” |
| 行宽不一致 | 少列补空字符串；多列在 50 列上限内补进表头，超出部分丢弃并提示 |
| 引号与换行 | 支持 RFC 4180：`""` 转义、引号内逗号与换行、CRLF/LF；字段内 CRLF 归一为 LF |
| 截断 | 读取被截断时丢弃最后一个不完整记录，并在状态栏提示“仅显示前 1 MiB” |
| 编码 | 沿用现有 UTF-8 / GB18030 / UTF-16LE / UTF-16BE 选择器；切换后重新渲染当前视图 |
| 错误 | 解析异常不抛出到页面，降级为原始文本并提示；空文件显示空表格提示 |

## 实现方案

### 1. 新增 `frontend/src/preview/delimitedText.ts`

- 导出 `parseDelimited(text, delimiter, { maxRows, maxColumns })`，返回 `{ header, rows, truncatedRows, truncatedColumns, malformed }`。
- 单次线性扫描实现，状态机处理引号、转义引号、CRLF/LF 与字段内换行；不以 `split` 简单切分。
- 去除开头 BOM；忽略末尾换行产生的空记录；`malformed` 标记未闭合引号。
- 配套 `delimitedText.test.ts`：引号、转义引号、字段内换行、CRLF、BOM、列宽不一致、行/列上限、空文件。

### 2. 扩展 `frontend/src/preview/engine.ts`

- `load()` 增加 `isDelimited = /\.(?:csv|tsv)$/i.test(path)`；在 `text/plain` 分支前进入 `showDelimitedTable()`。
- `showDelimitedTable()` 用 Range 读取字节，复用现有 UTF-16 BOM 判断，缓存到 `textBytes` 与 `textTruncated`，显示 `#textTools` 编码选择器，并渲染表格。
- 抽出 `renderTable(columns, rows, startRow)` 供 `renderSheet` 与 CSV 共用，避免两套 DOM 结构。
- 工具栏挂载 `.preview-csv-tools` 切换按钮（`aria-pressed`）：在表格与原始文本之间切换；表格视图状态栏显示“CSV 表格 · N 行 × M 列 · 截断提示”。
- 编码选择器的 `change` 事件在 CSV 模式下重新渲染当前视图，而不是只重建 `<pre>`。
- `destroy()` 清理新增的工具栏节点与容器类名。

### 3. 样式

- 复用 `.preview-spreadsheet-container`、`.preview-sheet-table-scroll`、`.preview-sheet-table`；仅为 `.preview-csv-tools` 增加与 `.preview-sheet-tabs` 一致的紧凑工具栏样式和窄屏规则。

### 4. 文档

- README 中关于预览能力的描述补充“CSV/TSV 直接以表格预览，原始文本可切换”。
- 更新本计划对应的 `docs/v0.12.0-progress.md`。
