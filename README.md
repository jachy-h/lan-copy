# Lan Copy

简体中文 | [English](README.en.md)

> 一个文件，整个局域网互传。无需安装、无需登录、无需网盘。

Lan Copy 是一个极小、零依赖的局域网快传工具。只需在一台电脑运行，同一 Wi-Fi / 局域网内的手机、平板、电脑打开网页即可互传文件和文字。

## 什么时候用它

- **手机 ↔ 电脑**：照片、视频、安装包，拖一下就过去，告别数据线
- **家人同事之间**：同一网络里互传大文件，不压缩、不限速、不过第三方
- **临时共享文字**：链接、验证码、命令、临时笔记，发出去对方一键复制

## 快速开始

1. **下载**：到 [Releases](https://github.com/jachy-h/lan-copy/releases/latest) 下载 Windows amd64 或 macOS Apple Silicon 压缩包并解压
2. **启动并打开**：
   - Windows：双击 `lan-copy.exe`，程序启动后会自动打开浏览器
   - macOS：打开终端，在解压目录中运行：

     ```bash
     cd /path/to/Lan-Copy-macOS-arm64
     ./lan-copy
     ```

     然后在浏览器打开 <http://localhost:8080>
3. **其他设备使用**：
   - 本机地址是 <http://localhost:8080>
   - 同一 Wi-Fi 下的其他设备，打开控制台显示的局域网地址（或用页面上的二维码扫码）
4. **停止**：在网页右上角点击"关闭软件"

Windows 启动后的控制台只是提示信息，按任意键即可关闭，服务会继续在后台运行。再次双击 exe 会打开已运行的网页，不会重复占用端口。

> 设备打不开？请允许 `lan-copy` 通过系统防火墙，并确认连接的是同一个局域网（访客 Wi-Fi 通常会隔离设备）。

不想下载？有 Go 1.22+ 环境也可以直接源码运行：

```bash
git clone https://github.com/jachy-h/lan-copy.git
cd lan-copy
go run .
```

默认共享文件夹：中文系统为 `共享文件夹-lancopy`，其他系统为 `shared-folder-lancopy`。原 `lan-copy-data` 在新目录不存在时会自动迁移；可通过 `-dir` 自定义目录。

## 在页面中更新

通过本机地址或局域网地址打开 Lan Copy，点击分享按钮左侧的齿轮，选择“更新”，将对应系统和架构的新版 `.zip` 或 `.tar.gz` 发布包拖入上传区域（也可点击选择）。校验通过后程序会自动替换、重启，页面恢复后自动刷新。请先完成其他文件传输。

更新只替换可执行程序，保留共享文件、文字、启动参数和工作目录。新版本启动检查失败时会尝试恢复并启动旧版本，详情保存在程序目录的 `lan-copy-update.log`。局域网其他设备也可上传签名更新包；`go run` 和 Docker 镜像禁用页面更新，Docker 请更新镜像。

更新包必须包含 `update.json` 和 `update.sig`，旧发布包不能直接用于此功能。所有更新均强制验证内置可信公钥的 Ed25519 签名；未配置或错误配置公钥时禁用更新。发布构建必须配置公钥及签名私钥，详见[更新发布说明](docs/UPDATING.md)。该功能是离线上传更新，不会自动联网检查或下载新版本。

## 它有什么特别

- **单文件**：Go 编译出的一个可执行文件，网页资源已内嵌，拷走就能用
- **零客户端**：电脑、手机、平板，有浏览器就能用
- **实时同步**：文件上传、移动、重命名或删除后，所有已打开的页面立即刷新；文件与文本列表每分钟自动刷新，悬停或点击“局域网在线”可查看最近成功的数据更新时间
- **共享空间**：默认首页提供文件夹浏览、新建文件夹、移动（含拖拽）、重命名、递归搜索（关键词高亮）和下载，支持直接拖入文件或整个文件夹（保留子目录和空目录）上传到当前文件夹，也可点击“上传文件夹”选择目录；上传同名文件夹时整份自动改名，不合并或覆盖；非空文件夹二次确认后可连同内容删除，移动时不会覆盖同名内容
- **浏览器预览**：图片列表显示缩略图，点击文件名即可查看常见图片（含 SVG）、播放浏览器支持编码的视频和音频、翻页缩放 PDF，以及查看文本和代码；文本预览前 256 KiB，可切换 UTF-8、GBK 和 UTF-16 编码。不支持的格式点击后仅提示，仍可下载；Office 文件暂不预览
- **传大文件**：流式写盘上传，不会把整个文件载入内存，默认单次上限 10 GiB
- **扫码访问**：顶部分享图标支持悬停或点击展开二维码和“分享地址，电脑打开”入口，自动检测可达的局域网地址
- **本机操作**：localhost / 回环地址访问时，文件列表将“下载”替换为“打开文件夹”，直接打开文件所在目录；其他设备仍可下载
- **覆盖保护**：同名文件自动保存为 `文件 (2).ext`
- **移动适配**：适配安全区域、触控尺寸和窄屏布局
- **零外部依赖**：后端仅使用 Go 标准库，无数据库；PDF.js 随程序内嵌，预览无需联网或额外安装

## 安全说明

Lan Copy 面向可信的家庭局域网，默认不设账号密码。局域网里的任何设备都可以查看、复制、删除共享内容，也可以通过网页关闭服务。请勿直接暴露到公网；在公司、校园或公共 Wi-Fi 中使用时也应谨慎。
